# Drawnumber

Jeu de coloriage par numéros, en une seule page web (`index.html`), sans dépendance ni étape de build.

- 78 dessins intégrés, classés par catégories : Pieuvres, Lettres, Chiffres, Formes, Nature
- Import d'une photo, convertie en grille numérotée (taille et nombre de couleurs au choix)
- Progression enregistrée dans le navigateur (localStorage)

## Lancer

Ouvrir `index.html` dans un navigateur, ou déployer le repo tel quel sur Vercel ou GitHub Pages.
